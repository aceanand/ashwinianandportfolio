# ⚡ Quick Start Guide

## 🎯 Get Your Portfolio Running in 3 Minutes!

### Step 1: Install (30 seconds)
```bash
npm install
```
Wait for dependencies to install...

### Step 2: Add Your Photo (1 minute)
1. Find your passport-style photo
2. Rename it to `profile.jpg`
3. Drop it in the `public` folder

```
portfolio/
└── public/
    └── profile.jpg  ← PUT IT HERE
```

### Step 3: Launch (30 seconds)
```bash
npm start
```

**That's it! Your portfolio is live at http://localhost:3000** 🎉

## 📱 Test on Mobile

1. Open DevTools (F12)
2. Click device toggle icon (Ctrl+Shift+M)
3. Select different devices
4. Watch your photo resize automatically!

**Sizes:**
- Desktop: 380x380px
- Tablet: 320x320px
- Mobile: 280x280px
- Small: 240x240px
